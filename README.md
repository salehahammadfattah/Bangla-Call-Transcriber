# বাংলা কল ট্রান্সক্রাইবার (BanglaCallTranscriber)

শ্রবণ প্রতিবন্ধী ব্যবহারকারীদের জন্য অফলাইন, রিয়েল-টাইম বাংলা কল ট্রান্সক্রিপশন অ্যাপ।

## ⚠️ জরুরি সীমাবদ্ধতা (আগে পড়ুন)

Android/iOS নিরাপত্তা নীতির কারণে থার্ড-পার্টি অ্যাপ সরাসরি ফোন-কলের অডিও
ইন্টারসেপ্ট করতে পারে না। তাই এই অ্যাপ **"স্পিকার + মাইক্রোফোন"** পদ্ধতিতে কাজ করে:

- কল রিসিভ করার পর ব্যবহারকারী **স্পিকার অন** করবেন
- অ্যাপ মাইক্রোফোন দিয়ে সেই আওয়াজ শুনে টেক্সটে রূপান্তর করবে
- মডেল একবার ডাউনলোড হলে ইন্টারনেট ছাড়াই কাজ করবে

এই কারণে আশেপাশের শব্দ ট্রান্সক্রিপশনে মিশে যেতে পারে — শান্ত পরিবেশে ব্যবহার করা ভালো।

## এই কনটেইনারে যা করা হয়েছে, যা করা হয়নি

✅ সম্পূর্ণ Android Studio প্রজেক্ট (Kotlin + C++/JNI কাঠামো) তৈরি করা হয়েছে
✅ অডিও ক্যাপচার (Foreground Service), UI, whisper.cpp-এর সাথে JNI ব্রিজ — সব কোড রেডি

❌ এই সার্ভারে Android SDK/NDK নেই, তাই এখান থেকে সরাসরি **.apk কম্পাইল করা সম্ভব হয়নি**
❌ এই সার্ভার থেকে HuggingFace.co অ্যাক্সেসযোগ্য না, তাই বাংলা মডেল **ডাউনলোড করে দেওয়া সম্ভব হয়নি**

তাই নিচের ধাপগুলো তোমাকে নিজের কম্পিউটারে (Android Studio দিয়ে) সম্পন্ন করতে হবে।
প্রতিটা ধাপ কপি-পেস্ট করার মতো করে লেখা আছে।

## 🚀 সবচেয়ে সহজ পথ — শুধু ফোন দিয়ে, GitHub Actions দিয়ে ক্লাউডে বিল্ড

কম্পিউটার লাগবে না। মডেল ডাউনলোড, কনভার্সন, আর APK বিল্ড — সবই GitHub-এর ফ্রি
ক্লাউড সার্ভারে হবে (`.github/workflows/build.yml` এটাই করে)। ধাপগুলো:

1. **GitHub অ্যাকাউন্ট বানাও** (না থাকলে) — [github.com](https://github.com), ফোনের ব্রাউজার দিয়েই করা যায়
2. **নতুন রিপোজিটরি বানাও** — GitHub অ্যাপ বা ব্রাউজারে "New repository" চাপো, নাম দাও যেমন `bangla-call-transcriber`, Public/Private যেকোনোটা, "Create"
3. **এই জিপ ফাইলের সব কনটেন্ট আপলোড করো** —
   - প্রথমে জিপ ফাইলটা ফোনে এক্সট্র্যাক্ট করো (যেকোনো ফাইল ম্যানেজার/ZIP অ্যাপ দিয়ে)
   - রিপোর পেজে "Add file" → "Upload files" চাপো
   - এক্সট্র্যাক্ট করা ফোল্ডারের ভেতরের সব ফাইল/ফোল্ডার সিলেক্ট করে আপলোড করো
   - **গুরুত্বপূর্ণ:** `.github` ফোল্ডারটা (হিডেন ফোল্ডার, ডট দিয়ে শুরু) যেন বাদ না যায় —
     ফাইল ম্যানেজারে "হিডেন ফাইল দেখাও" অপশন অন করে নিশ্চিত হও এটা আপলোড হয়েছে
   - "Commit changes" চেপে আপলোড শেষ করো
4. **ওয়ার্কফ্লো চালু করো** — রিপোর ওপরে "Actions" ট্যাবে যাও, বাম পাশে
   "Build Bangla Call Transcriber APK" এ ক্লিক করো, ডান পাশে "Run workflow" বাটন
   চাপো → আবার সবুজ "Run workflow" চাপো
5. **অপেক্ষা করো** — বিল্ড শুরু হবে (মডেল ডাউনলোড+কনভার্সন+APK কম্পাইল মিলিয়ে
   ৩০-৬০ মিনিট লাগতে পারে, মডেল সাইজের ওপর নির্ভর করে)। "Actions" ট্যাবে
   প্রগ্রেস দেখা যাবে (হলুদ বৃত্ত = চলছে, সবুজ টিক = সফল, লাল ক্রস = ব্যর্থ)
6. **APK ডাউনলোড করো** — সফল হলে সেই রানের পেজে নিচের দিকে "Artifacts" সেকশনে
   `BanglaCallTranscriber-debug-apk` নামে একটা জিপ পাবে, ট্যাপ করে ডাউনলোড করো
7. **ইনস্টল করো** — ডাউনলোড হওয়া জিপ থেকে `.apk` ফাইল বের করে ট্যাপ করো;
   "Unknown sources" ইনস্টল অনুমতি চাইলে দিয়ে দাও

এরপর থেকে যেকোনো কোড পরিবর্তন করে আবার "Run workflow" চাপলেই নতুন APK পাবে।

**যদি বিল্ড ব্যর্থ (লাল ক্রস) হয়:** Actions পেজে সেই রানে ক্লিক করে লগ পড়ো —
কোন ধাপে সমস্যা হয়েছে বুঝিয়ে দেবে। লগের প্রাসঙ্গিক অংশ আমাকে পাঠালে সমাধান
বের করতে সাহায্য করতে পারব।

## বিকল্প: নিজের কম্পিউটারে বিল্ড করা

যদি ক্লাউড বিল্ডের বদলে নিজের কম্পিউটারে করতে চাও, নিচের ধাপ অনুসরণ করো।

## ধাপ ১: প্রয়োজনীয় সফটওয়্যার ইনস্টল করো

1. [Android Studio](https://developer.android.com/studio) ইনস্টল করো (এতে Android SDK+NDK+CMake বিল্ট-ইন অপশন হিসেবে আসে — ইনস্টলের সময় "NDK" আর "CMake" চেকবক্স টিক দিও)
2. Git ইনস্টল করা থাকতে হবে
3. Python 3.8+ (মডেল কনভার্সনের জন্য)

## ধাপ ২: প্রজেক্ট খোলো এবং whisper.cpp যোগ করো

এই পুরো ফোল্ডারটা (`BanglaCallTranscriber`) একটা গিট রিপোতে রূপান্তর করে whisper.cpp সাবমডিউল হিসেবে যোগ করো:

```bash
cd BanglaCallTranscriber
git init
git add .
git commit -m "initial project"

git submodule add https://github.com/ggml-org/whisper.cpp.git app/src/main/cpp/whisper.cpp
git submodule update --init --recursive
```

তারপর Android Studio-তে "Open" করে এই ফোল্ডারটা সিলেক্ট করো। Gradle sync হতে দাও (প্রথমবার একটু সময় নেবে)।

## ধাপ ৩: বাংলা Whisper মডেল সংগ্রহ ও কনভার্সন

আমরা রিসার্চ করে দেখেছি সবচেয়ে ভালো বাংলা মডেল হলো:
**`bangla-speech-processing/BanglaASR`** (Whisper-small ভিত্তিক, Word Error Rate ৪.৫৮%)

এই মডেলটা মূলত PyTorch ফরম্যাটে আছে, whisper.cpp-এর জন্য GGML ফরম্যাটে কনভার্ট করতে হবে:

```bash
# whisper.cpp সাবমডিউলের ভেতরে
cd app/src/main/cpp/whisper.cpp

# কনভার্সনের জন্য Python লাইব্রেরি ইনস্টল করো
pip install -r models/requirements-convert-hf-to-ggml.txt

# HuggingFace থেকে মডেল কনভার্ট করা (নেট লাগবে, তোমার নিজের কম্পিউটারে চালাও)
python models/convert-h5-to-ggml.py bangla-speech-processing/BanglaASR ./models/bangla-ggml

# ঐচ্ছিক: মোবাইলের জন্য সাইজ ছোট করতে quantize করো (নির্ভুলতা সামান্য কমবে)
# বিল্ড হওয়া quantize টুল ব্যবহার করে:
./build/bin/quantize ./models/bangla-ggml/ggml-model.bin ./models/bangla-ggml-q5.bin q5_0
```

এই স্ক্রিপ্ট আর একটু ভিন্ন হতে পারে whisper.cpp-এর সর্বশেষ ভার্সনে — সাবমডিউলের
`models/README.md` ফাইলে হালনাগাদ নির্দেশনা দেখে নাও।

**বিকল্প (সহজ পথ):** যদি কনভার্সন ঝামেলার মনে হয়, Hugging Face-এ সরাসরি খুঁজে দেখো
কেউ ইতিমধ্যে GGML ফরম্যাটে বাংলা Whisper মডেল আপলোড করে রেখেছে কিনা —
`https://huggingface.co/models?search=bangla+whisper+ggml` এ সার্চ করে দেখো।

## ধাপ ৪: মডেল অ্যাপে বসানো

কনভার্ট করা `.bin` ফাইলটার নাম দাও `bangla-whisper.bin`, তারপর এখানে রাখো:

```
app/src/main/assets/models/bangla-whisper.bin
```

`MainActivity.kt`-এ ইতিমধ্যে কোড আছে যা অ্যাপ প্রথমবার চালু হলে এই ফাইলটা
automatically internal storage-এ কপি করে নেবে — তাই ADB দিয়ে আলাদা করে
কিছু পুশ করার দরকার নেই, শুধু বিল্ড করার আগে ফাইলটা ওই assets ফোল্ডারে রাখলেই হবে।

⚠️ মনে রাখবে: মডেল ফাইল APK-এর ভেতরেই বান্ডল হয়ে যাবে, তাই APK-এর সাইজ
মডেলের সাইজের সমান বেড়ে যাবে (base মডেলে ~২৫০MB, small-এ ~১GB)।

## ধাপ ৫: বিল্ড ও রান

Android Studio-তে ফোন (USB ডিবাগিং অন করা) কানেক্ট করে সবুজ ▶ বাটনে চাপো,
অথবা টার্মিনালে:

```bash
./gradlew assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk
```

## ধাপ ৬: ব্যবহার

3. স্বাভাবিক ফোন-কল রিসিভ করে **স্পিকার অন করো**
4. অপর পাশের কথা কয়েক সেকেন্ড পর পর টেক্সট হয়ে স্ক্রিনে আসবে
